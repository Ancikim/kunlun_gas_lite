# 昆仑燃气 · Home Assistant 集成（轻量版）

把**中石油昆仑燃气**（微信小程序 / H5 缴费平台 `bol.grs.petrochina.com.cn`）的用气数据接进 Home Assistant。

不用模拟登录、不用账号密码：核心数据来自一个**免密公开接口**，只要户号 + 地区码就能查到表端余额、欠费、表读数、最后通信时间。想再要日用气曲线、月用气、账单、阶梯气价，可以额外填一个小程序里的 `Authorization` 令牌。

> 本仓库代码不含任何真实户号、姓名、手机号、表号或令牌，首次配置全部由你自己填写。

## 两种模式

| 模式 | 需要填什么 | 能拿到 |
| --- | --- | --- |
| 免密（默认） | 户号 + 地区 | 表端余额、欠费、账户余额、表读数、最后通信、最近账单气费、可缴费状态 |
| 完整（可选） | 再加 `Authorization` 令牌 | 以上全部 + 最近一日用气/读数、近 31 日用气、本月用气、本年累计、阶梯档位/单价/剩余、账单数 |

令牌是服务端下发的短命凭证（opaque，非 JWT，**实测有效期 ≤ 3 天**，不可自动续期）。令牌过期或填错时，集成会自动降级回免密模式，**不会导致整个集成报错**，在「设置」里粘贴新令牌即可恢复。

## 安装

### 方式一：HACS 自定义仓库

1. HACS → 右上角 `⋮` → **自定义存储库**
2. 填入本仓库地址，类型选 **Integration**
3. 搜索「昆仑燃气」安装，重启 Home Assistant
4. 设置 → 设备与服务 → 添加集成 → 搜索「昆仑燃气」

### 方式二：手动

把 `custom_components/kunlun_gas_lite` 整个目录复制到 HA 配置目录的 `custom_components/` 下，重启 HA。

```
config/
└── custom_components/
    └── kunlun_gas_lite/
        ├── __init__.py
        ├── config_flow.py
        ├── const.py
        ├── coordinator.py
        ├── manifest.json
        ├── regions.py
        ├── sensor.py
        ├── strings.json
        ├── brand/
        └── translations/
```

## 配置

配置分两步，**都不带默认值**，需要你自己选、自己填：

1. **选择地区** —— 下拉里是接口公开返回的全国 **227 家**昆仑燃气公司（可输入关键字筛选），选中后自动带出地区码 `mdmCode` 与地区编号 `ouId`。
2. **填写户号** —— `userCode`（一般 8~10 位，见小程序「我的」或缴费记录）。地区码/编号已自动填好，通常不用改。
   - 可选：`Authorization` 令牌 → 升级为完整模式
   - 可选：账户编号 `accountId`、表号 `badgeNumber`（填了会让部分进阶接口更稳）

多个户号可以重复添加多次，每个户号一套设备。

### 令牌从哪里来

在微信里打开昆仑燃气小程序，进入缴费/账单页，用抓包工具（如 Windows 版 Fiddler、手机端 HttpCanary）查看发往 `bol.grs.petrochina.com.cn` 的请求，复制请求头 `Authorization` 的值（`Bearer xxx` 整段或只留后面的串都行）粘贴进「令牌」框。集成会自动清掉空格、换行和 `Bearer` 前缀。

## 实体

设备为「昆仑燃气 <户号>」，共 16 个传感器：

- **免密常驻（7）**：表端余额、欠费金额、账户余额、燃气表读数、表具最后通信、最近账单气费、是否可缴费
- **需令牌（9）**：最近一日用气、最近一日表读数、近31日用气、本月用气、本年累计用气、当前阶梯档位、当前阶梯单价、距下一阶梯、账单数

没有令牌或令牌失效时，后 9 个实体保留但显示为「不可用」，不会反复增删实体，仪表盘里的引用不会丢。

表端余额 / 表具最后通信等实体的属性里会带上接口返回的户名、地址、脱敏手机号、账户编号等，方便在「更多信息」里核对。刷新间隔默认 3600 秒（最小 1800 秒），可在集成「配置」里改。

## 说明与限制

- 数据接口为本平台自身使用的内部接口，**非官方开放 API**，可能随时变更；变更后集成需要跟着修。
- 只有**远传燃气表**（能自动上报读数的表）才有余额与表读数；普通 IC 卡表可能查不到。
- 部分公司（如需要预存费的地区）接口返回字段可能缺失，实体显示 `未知` 属正常。
- 未做「缴费」「充值」等写操作，仅读取。
- 与中石油昆仑燃气官方无任何关联，仅供个人自用。
